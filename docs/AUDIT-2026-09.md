security, performance, backend code quality, web + design system, SEO/GEO), each by a

change that has a number. Status column: `open` · `fixing` · `done <sha>` · `deferred <why>`.

## MEDIUM (condensed; full rows in the lens reports)

- **Ops**: with `PRISM_LANGFUSE_ENABLED=false` the worker still emits `Failed to export span batch code: 404` every few seconds (67 on one deployment) — the `langfuse.openai` import starts an OTel exporter regardless of the flag; gate the import or set `LANGFUSE_TRACING_ENABLED=false`.
- **Security**: DNS-rebinding TOCTOU in `common/imagehash.py:30-60` guard; `/api/docs` open in prod (`api/main.py:32-34`); Langfuse keys re-exported to `os.environ` (`config.py:274-300`).
- **Architecture**: lazy-import cycles (`common/outlets.py:128`, `ingestion/base.py:77`, `partition.py:41-48`); `note_edition` vs correlation lost update on `events.regions`; no CHECK on any status column, directional `event_links` uniqueness; `prism_veto_enabled` defaults to a known-broken path; 12 bare `os.environ` reads beside 59 settings; embed model/dim as settings; `reconcile_stories`/`_budget_watch` unlocked; `@observe` on `canonical_title` not the handler; stream envelopes lack `v`/`origin`.
- **API**: inconsistent error shapes/envelopes across route files; untyped `dict` returns in `serialization.py`; no cache headers on public reads.
- **Performance**: `/feed/counts` six unbounded COUNTs per page load; `_story_component` DF-CTE recompute per BFS node; duplicate-URL re-embed; podcasts/xposts `match_recent` N+1 (~400 windows/run); `_apply_veto` sequential across stories; classification `concurrency=4` unmeasured; `max_tokens=2500` on thread-link.
- **Quality**: `evals/run_all.py:94` mutation; silent `except: pass` in `stream.py:96-104`, `agent/structure.py:99`, `threads.py:613`; single-letter bindings in the two `match_recent`; `worker/__main__.py:main` 160 lines; 74 public functions without return types.
- **Web**: `lib/api.ts` (840) one file for every endpoint; `label/[key]/page.tsx` 1,018; `StoryView.tsx` 775; client-side refetch of SSR'd data; a11y gaps on lens tabs / Ask focus.
- **SEO**: opaque UUID record URLs (slug + short-id like `/trending`); outlet photos as raw `<img>` (LCP/CLS); `/` has no canonical; no `sameAs`/`ContactPoint`; `force-dynamic` on story and arc pages (no ISR); no hreflang / Indic surface (product decision); no `BreadcrumbList`; machine bylines vs Publisher Center's editorial-accountability bar.
